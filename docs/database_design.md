# ResearchMind AI – Database Design

## Overview

PostgreSQL is used for all persistent application data.
Qdrant is used separately for vector embeddings (not described here).

## Tables

### users
Stores registered user accounts.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Unique user identifier |
| email | VARCHAR(255) UNIQUE | User email address |
| hashed_password | TEXT | bcrypt-hashed password |
| full_name | VARCHAR(255) | Display name |
| is_active | BOOLEAN | Account active flag |
| created_at | TIMESTAMP | Account creation time |
| updated_at | TIMESTAMP | Last update time |

### research_projects
Top-level research jobs created by users.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Research job ID |
| user_id | UUID (FK → users.id) | Owning user |
| topic | TEXT | Original research topic |
| depth | VARCHAR(20) | quick / standard / comprehensive |
| mode | VARCHAR(20) | web / documents / hybrid |
| status | VARCHAR(30) | See ResearchStatus enum |
| language | VARCHAR(50) | Report language |
| retry_count | INTEGER | Times the workflow retried |
| error_message | TEXT | Last error if failed |
| created_at | TIMESTAMP | When job was created |
| started_at | TIMESTAMP | When research began |
| completed_at | TIMESTAMP | When research finished |

### research_plans
The structured plan generated by the Planner Agent.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Plan ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| scope_and_objectives | TEXT | Research scope |
| information_categories | JSONB | List of category strings |
| estimated_duration_minutes | INTEGER | Estimated duration |
| approved_at | TIMESTAMP | When user approved |
| created_at | TIMESTAMP | When plan was created |

### research_questions
Individual research questions within a plan.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Question ID |
| plan_id | UUID (FK → research_plans.id) | Parent plan |
| question | TEXT | The research question |
| category | VARCHAR(100) | Category label |
| priority | INTEGER | 1=high, 2=medium, 3=low |
| search_queries | JSONB | List of search query strings |
| rationale | TEXT | Why this question matters |
| order_index | INTEGER | Display order |

### research_sources
Real sources collected by the Researcher Agent.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Source ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| question_id | UUID (FK → research_questions.id) | Which question it answers |
| title | TEXT | Source title |
| url | TEXT | Original URL |
| domain | VARCHAR(255) | Domain extracted from URL |
| excerpt | TEXT | Relevant text snippet |
| published_date | VARCHAR(50) | Publication date if available |
| relevance_score | FLOAT | Relevance 0.0–1.0 |
| is_duplicate | BOOLEAN | Marked as duplicate |
| retrieved_at | TIMESTAMP | When source was collected |

### research_findings
Findings generated by the Analyst Agent.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Finding ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| category | VARCHAR(100) | Finding category |
| finding | TEXT | The finding statement |
| evidence_source_ids | JSONB | List of source UUIDs |
| confidence | FLOAT | Analyst confidence 0.0–1.0 |
| is_trend | BOOLEAN | Marked as a trend |
| is_opportunity | BOOLEAN | Marked as opportunity |
| is_risk | BOOLEAN | Marked as a risk |
| is_contradiction | BOOLEAN | Contradiction between sources |

### verified_claims
Claims assessed by the Fact Checker Agent.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Claim ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| claim | TEXT | The exact claim text |
| status | VARCHAR(30) | VERIFIED / PARTIALLY_SUPPORTED / UNSUPPORTED / CONTRADICTED / NEEDS_MORE_EVIDENCE |
| reasoning | TEXT | Why this status was assigned |
| supporting_source_ids | JSONB | Supporting source UUIDs |
| contradicting_source_ids | JSONB | Contradicting source UUIDs |
| note | TEXT | Additional context |

### research_reports
Final reports generated by the Report Writer Agent.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Report ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| title | TEXT | Report title |
| executive_summary | TEXT | Summary |
| objectives | TEXT | Research objectives |
| methodology | TEXT | How research was conducted |
| key_findings | JSONB | List of key finding strings |
| detailed_analysis | TEXT | Full analysis text |
| industry_trends | JSONB | List of trend strings |
| opportunities | JSONB | List of opportunity strings |
| risks_and_challenges | JSONB | List of risk strings |
| uncertain_findings | JSONB | Unverified findings (flagged) |
| limitations | TEXT | Research limitations |
| conclusion | TEXT | Conclusion |
| word_count | INTEGER | Total word count |
| pdf_path | TEXT | Path to generated PDF file |
| created_at | TIMESTAMP | Report creation time |

### uploaded_documents
Documents uploaded by users for RAG research.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Document ID |
| user_id | UUID (FK → users.id) | Owning user |
| filename | VARCHAR(500) | Original filename |
| file_path | TEXT | Storage path |
| file_size_bytes | INTEGER | File size |
| mime_type | VARCHAR(100) | Content type |
| page_count | INTEGER | Number of pages |
| chunk_count | INTEGER | Number of chunks indexed |
| qdrant_collection | VARCHAR(100) | Qdrant collection name |
| indexed_at | TIMESTAMP | When vectorized |
| created_at | TIMESTAMP | When uploaded |

### agent_execution_logs
Detailed logs of each agent execution step.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Log ID |
| research_id | UUID (FK → research_projects.id) | Associated research job |
| agent_name | VARCHAR(50) | Which agent ran |
| event_type | VARCHAR(50) | started / completed / failed / retry |
| message | TEXT | Log message |
| metadata | JSONB | Extra context (token count, etc.) |
| created_at | TIMESTAMP | Event time |

### usage_records
API usage tracking for analytics and cost estimation.

| Column | Type | Description |
|---|---|---|
| id | UUID (PK) | Record ID |
| user_id | UUID (FK → users.id) | User |
| research_id | UUID | Associated research job |
| service | VARCHAR(50) | gemini / tavily / qdrant |
| operation | VARCHAR(50) | generate_content / search / upsert |
| tokens_used | INTEGER | LLM tokens if applicable |
| cost_estimate_usd | FLOAT | Estimated cost |
| created_at | TIMESTAMP | When the call was made |

## Indexes

Key indexes for performance:
- `research_projects(user_id, created_at DESC)` – user's research history
- `research_sources(research_id)` – sources for a job
- `research_questions(plan_id)` – questions for a plan
- `agent_execution_logs(research_id, created_at)` – live monitoring
- `uploaded_documents(user_id)` – user's document library
